🧠 Карта об'єктів, класів і методів Python

Рівень:

Клікніть (або виберіть клавішею Tab і натисніть Enter) будь-який клас або об'єкт на схемі — числа, рядки, списки, ваші класи і навіть функції: вони теж об'єкти. Для об'єктів можна викликати методи і побачити, де Python їх знаходить і що вони роблять з об'єктом.

__class__ — «є екземпляром» __bases__ — «успадковується від» клас є екземпляром type __self__ — до кого прив'язано метод
Що метод робить з об'єктом: змінює сам об'єкт нове повертає новий об'єкт дані лише читає / відповідає створення працює при створенні None метод вимкнено

📐 Межі моделі: що спрощено в цій карті

  • Методи вибрані, а не всі. У кожного класу показано найважливіші методи; повний список дає dir(obj).
  • MRO рахується алгоритмом C3, як у Python, але на схемі всі класи мають одного батька. Множинне успадкування (class Z(X, Y)) — урок 21.
  • Пошук атрибута без дескрипторів. Насправді @property та інші дескриптори даних у класі перемагають obj.__dict__ (урок 24).
  • id() умовний. Тут це лічильник симуляції, а не реальна адреса в пам'яті.
  • __init__ не завжди викликається: лише коли __new__ повернув екземпляр цього класу.
  • object.__eq__ для різних об'єктів повертає NotImplemented; оператор == тоді пробує other.__eq__, а в підсумку дає False.
  • Копії поверхневі: list.copy(), + і зрізи створюють новий зовнішній список, але елементи в ньому ті самі об'єкти.
  • Кортеж хешується, лише якщо всі елементи хешовані: hash(([1, 2], 540)) → TypeError.
