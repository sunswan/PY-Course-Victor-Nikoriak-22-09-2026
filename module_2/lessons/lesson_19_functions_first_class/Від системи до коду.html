    Власниця «Смачно + Таксі» щотижня просить нове: промокоди SUMMER10, VIP20, WELCOME5, тариф за районом, повідомлення в SMS і Telegram. У коді модуля 1 кожне прохання означало ще один elif. Сьогодні ти спроєктуєш систему зверху вниз: спершу схема, потім функції, і лише наприкінці код.

    Правила маршруту

    Сім станцій. На кожній зліва задача на схемі системи, справа закритий код. Розв'яжи задачу, і код відкриється: побачиш, як твоє рішення виглядає в Python. Зелена станція на лінії вгорі означає «пройдено».

    Стрілки ← → на клавіатурі гортають станції.

    Станція 2 · рівень «Потік»
    
  
    Розклади ящик на станції конвеєра

    Станція 3 · рівень «Функції»
    
  
    Чисте ядро, брудні краї
    
  
    Конвеєр працює надійно лише тоді, коли його кроки чисті: той самий вхід завжди дає той самий вихід, і зовні нічого не змінюється. Файли, мережа, годинник і print теж потрібні, але вони живуть на краях системи.
    
  
    
    
    
      
    Система
    
      
    
        
    Ядро
    Обчислює. Повертає новий об'єкт. Тестується одним assert.
    
        
    Край
    Торкається світу: файл, мережа, час, мутація чужих даних.
    
      
    
      
    Місія: для кожної функції обери Ядро або Край.
    
      
    
      
    
      
    
    
    
    
    Код · Pythonpure functions
    
      
    Розклади функції, щоб побачити різницю між append і +.
    
  
    

    



    
  
    Станція 4 · рівень «Функції»
    
  
    Довідник промокодів і фабрика
    
  
    Промокоди відрізняються лише відсотком, тож відсоток — це дані, а не код. Замість функцій-близнюків тримаємо один довідник PROMOS (конфігурацію). Зв'язати його з функцією можна через partial або через фабрику, яка зберігає довідник у замиканні.
    
  
    
    
    
      
    Система
    
      
    def apply_summer10(t): return t * 0.90
def apply_vip20(t):    return t * 0.80
def apply_welcome5(t): return t * 0.95   # і так для кожного коду
    
      
    Місія: додай у довідник VIP20 (20 %) та WELCOME5 (5 %). Зверни увагу: код функцій праворуч при цьому не змінюється.
