# Модулі курсу (в розробці)

Програма v5.0 складається з 6 модулів + капстоуну (М6) + самостійного бонусного треку з AI. Джерело — навігаційна таблиця `data/PY_UKR_Navigation_table_5 [UPDATE].xlsx` (46 уроків + 6 класних практикумів, ≈134 год. аудиторно, плюс 14 год. самостійного AI-треку).

Контент модулів наповнюється поступово — спочатку два пілотні уроки, потім решта, за планом у `data/plan_md/migration_plan.md`.

| Модуль | Уроки (за v5.0) | Сторінка |
|---|---|---|
| М1. Основи Python | 1–17 | [m1/index.md](m1/index.md) |
| М2. Python Advanced | 18–28 | [m2_python_advanced.md](m2_python_advanced.md) |
| М3. Бази даних | 29–30 | [m3_databases.md](m3_databases.md) |
| М4. Web (+ Web Advanced) | 31–47 | [m4_web.md](m4_web.md) |
| М5. Production | 48–50 | [m5_production.md](m5_production.md) |
| М6. Капстоун | 51–52 | [m6_capstone.md](m6_capstone.md) |
| Self-paced. AI для розробників (бонус) | поза наскрізною нумерацією | [bonus_ai.md](bonus_ai.md) |

Номери уроків — номери з навігаційної таблиці v5.0. Папки уроків мають ту саму нумерацію: `module_N/lessons/lesson_NN_<тема>/`, де `NN` — номер уроку v5.0 (наприклад, урок 5 → `module_1/lessons/lesson_05_lists_tuples_sets/`). Матеріали зі старого курсу (23_02) лежать у папці того уроку v5.0, до якого вони належать. Як відкривати ноутбуки — [Ноутбуки в Google Colab](../00_getting_started/colab.md).
