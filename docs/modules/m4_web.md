# М4. Web (+ Web Advanced)

Програми говорять мережею: спершу — як клієнт до чужих API, далі — власні сервери на Django і FastAPI.

Уроки модуля:

- [Урок 31. HTTP: requests, httpx, aiohttp](m4/lesson_31.md) — шлях запиту: URL, IP і DNS, порти, TCP-рукостискання, TLS; HTTP як текст (запит сокетом), методи й статус-коди; `requests`: `params`, `json`, заголовки й токен, `raise_for_status`, тайм-аути й ієрархія винятків, повторні спроби з backoff і чому не для `POST`, `Session`; справжній API PyPI; `httpx` і `AsyncClient` + `gather`, `aiohttp`, потоки; архітектура: свій клієнт до API з доменними винятками, вибір бібліотеки. Практика — на навчальному API диспетчерської `smachno_api.py`.
- [Урок 32. REST: принципи дизайну API](m4/lesson_32.md) — метео-API викладача (телеграми SYNOP з ogimet.com, `pymetdecoder`): усі типи API на одних даних — HTTP+CSV, JSON-RPC, GraphQL, SOAP, gRPC, WebSocket, SSE, webhook з підписом HMAC — і як обрати; REST: ресурси й URL, методи й ідемпотентність, статус-коди й формат помилок, фільтри, `fields`, пагінація, `PATCH`, `202 Accepted`, OpenAPI; кейс v1 → v2; архітектура: репозиторій → FastAPI → клієнт-клас → Streamlit-карта погоди, Docker Compose.
- [Урок 33. Django intro: MVT, ORM, admin](m4/lesson_33.md) — перший крок застосунку нотаток, що виросте до [Notes Chat App](https://github.com/NikoriakViktot/notes_chat_app) викладача (кроки 1–2 маршруту [Zero to Hero](https://nikoriakviktot.github.io/notes_chat_app/tutorials/) Django-книги): `startproject` / `startapp`, `settings.py`, MVT і шлях запиту, view, `path` / `include`, модель `Note`, `makemigrations` / `sqlmigrate` / `migrate`, ORM (`create`, `filter`, lookups, `get`, лінивий QuerySet, `.query`, `update`, `delete`), шаблон, адмінка й суперкористувач; практика — `is_pinned`, `priority`, блокноти.
- [Урок 34. Django: forms, HTML practice](m4/lesson_34.md) — два рефакторинги проєкту уроку 33 на коді старого курсу (кроки 2 і 4 Django-книги): голий HTML → Bootstrap CRUD (`ModelForm`, PRG, `messages`, `base.html`, CSRF) і Bootstrap → crispy dashboard (3-рівневі шаблони, `FormHelper` + `Layout`, context processor); «Знайди помилку» — `is_pinned` губиться при створенні.
- [Урок 35. DRF overview + Django vs FastAPI](m4/lesson_35.md) — рефакторинг 3 проєкту уроку 34: REST API поруч зі сторінками поверх тих самих services/selectors (код з Django-книги): `REST_FRAMEWORK`, вхідний і вихідний серіалізатори, `ViewSet` + `DefaultRouter`, `@action` `pin`, `IsAuthenticated` і чому `403`, IDOR → `404`, `PATCH` з `partial=True`, browsable API, OpenAPI (drf-spectacular + `extend_schema`), тести; той самий API на FastAPI і як обрати; «Знайди помилку» — `auto_now` не оновлюється з `update_fields`.
- [Урок 36. Typing + Pydantic](m4/lesson_36.md) — крок 1 новинного агрегатора (FastAPI-гілка): парсер `parse_rbc_news` зі старого курсу з анотаціями типів (`list[RawNews]`, `TypedDict`, `X | None`, `Literal`), `mypy` і `--strict`, модель `NewsItem` на Pydantic (`Field`, `field_validator`, `model_validator(mode="before")`, `frozen`), перевірка знімка 168 справжніх новин rbc.ua, `validate_news` без мовчазних втрат, JSON Schema, `TypeAdapter`; «Знайди помилку» — URL, розібраний рядком.
- [Урок 37. FastAPI basics + Postman + OpenAPI](m4/lesson_37.md) — крок 2 агрегатора: FastAPI над `NewsItem` з `news_dashboard` старого курсу — маршрути, `Query` і `Literal`, `422`, `response_model`; сховище через `Depends` і `lifespan`, підміна залежностей у тестах; `POST /api/scrape` (aiohttp, `gather`, знімок, захист від SSRF); `/docs` і `/openapi.json`; колекція Postman з перевірками і newman; виміри `fastapi_demo`: `async def` + `time.sleep` — 20 запитів за 40 с, `def` і `await` — за 2 с (і як тест навантаження вимірював сам себе). Довідник: [FastAPI — архітектура і async](m4/fastapi/fastapi_documentation.md).
- [Урок 38. FastAPI + SQLAlchemy: повний CRUD](m4/lesson_38.md) — крок 3 агрегатора: `NewsStore` → PostgreSQL/SQLite на шарі бази `production_bot` старого курсу — async-engine і сесія на запит (`get_db`), `NewsRow` (`Mapped`), `NewsRepository` з тим самим інтерфейсом, SQL, який генерує SQLAlchemy, `INSERT … ON CONFLICT DO NOTHING` покроково (і чому id «перескакують»); повний CRUD `201/404/409/204`, пошук; Alembic-міграції; з FastAPI 0.118 COMMIT у `yield`-залежності йде після відповіді → `scope="function"`; «Знайди помилку» — гонка «перевір, потім встав».
- [Урок 39. Middlewares і кешування (Redis на практиці)](m4/lesson_39.md) — крок 4 агрегатора: HTTP-middleware (`X-Request-ID`, `X-Process-Time`, порядок шарів покроково); кеш `GET /api/news` і `/stats` у Redis (cache-aside, версія кешу, інвалідація **після COMMIT**); rate limit з `ai_bot` старого курсу — `429` і `Retry-After`, атомарні `INCR` + `EXPIRE NX` замість «ключ без TTL блокує назавжди», межа фіксованого вікна виміряна; фоновий збір `202` + статус у Redis з polling; «Знайди помилку» — сесія запиту у фоновій задачі: «збережено 168», а в базі 0.
- [Урок 40. Автентифікація та security basics (JWT, hashing, OWASP)](m4/lesson_40.md) — рефакторинг 4 застосунку нотаток на коді уроку автентифікації старого курсу: нотатки групи (`Q(user) | Q(group__in=…)`, читати — учасникам, змінювати — автору), перевірка автора в API → `403`; паролі — PBKDF2 з сіллю, скидання листом без розкриття акаунтів; JWT на `simplejwt` (header.payload.signature покроково, підправлений / чужий / прострочений токен → `401`, refresh з ротацією, порядок автентифікаторів DRF: `401` чи `403`), throttle `/api/token/`; `check --deploy`; OWASP Top 10 на нашому коді; «Знайди помилку» — `SECRET_KEY` у публічному репозиторії.
- [Урок 41. Тестування API (pytest + httpx)](m4/lesson_41.md) — рефакторинг 5 агрегатора новин: переробляємо лише тести уроку 39 за `lesson_Django_Testing` старого курсу. Шари unit / integration з маркерами; збережені сторінки rbc.ua як фікстури й тест конвеєра «парсер → модель»; мок мережі й «patch where used» (покрокова діаграма); фейковий HTTP-сервер (`aiohttp` `TestServer`) і межа фейку (fakeredis не показує гонок); `httpx.AsyncClient` + `ASGITransport` для одночасних запитів; покриття гілок з `concurrency = greenlet`; прогін на мінімальних версіях залежностей. Тести ловлять 4 помилки: ISO-час, битий байт UTF-8, `fakerbc.ua`, beautifulsoup4 4.12. «Знайди помилку» — два зелені тести, які разом пропустили помилку контракту.
- [Урок 42. AI-інструменти розробника + ризики й валідація](m4/lesson_42.md) — рефакторинг 6 агрегатора новин і рецензія AI-проєкту старого курсу. `news_hub` отримує `CLAUDE.md` (замість застарілого прикладу зі старого довідника), `.claude/settings.json` (allow / ask / deny), hook `pytest -m unit` після кожної правки і skill `/add-news-source`. Експеримент: Claude Code двічі додає RSS «Української правди» — з голим запитом (101 зелений власний тест, але час у GMT, тиха відмова на битому XML і вигадана фікстура) і за специфікацією з тестів (2 файли, тести не змінено); рецензія знаходить ще 3 випадки поза специфікацією. `allow` з репозиторію не діє без довіри до папки. Кейс `depression_dashboard` (Flask + Streamlit + scikit-learn, згенерований AI): 17 тестів рецензії доводять 10 вад, зокрема алфавітний порядок «топ-ознак» через `jsonify`, вигадані назви кластерів, підробні похідні ознаки в `/api/predict`, витік даних, незахищений `/api/train`. Довідник [Claude Code](m4/ai/claude_code.md) — з довідника старого курсу, звірений з документацією.

Решта уроків — 🚧 у розробці.
